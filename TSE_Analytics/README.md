# 🗳️ Projeto End-to-End: TSE Analytics 2026

Este repositório contém os scripts e a estrutura de dados desenvolvidos no projeto [TSE Analytics 2026](https://www.youtube.com/watch?v=TNW990c3Vh4) do canal Téo Me Why. 

O projeto é um pipeline de dados de ponta a ponta que realiza a coleta, o tratamento e a disponibilização dos dados públicos abertos do Tribunal Superior Eleitoral (TSE), como informações de candidatos, bens declarados e resultados das urnas.

## 🚀 Escopo do Projeto
* **Ingestão de Dados:** Scripts em Python para download automatizado e descompactação de grandes volumes de dados eleitorais.
* **Processamento:** Limpeza e estruturação dos dados brutos utilizando o ecossistema Python.
* **Análise:** Preparação das bases para cruzamentos, geração de estatísticas e identificação de padrões eleitorais.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python
* **Bibliotecas Principais:** `pandas` (manipulação de dados), `requests` (requisições HTTP), `rich` (formatação de terminal).
* **Ambiente:** VS Code / Jupyter
* **Versionamento:** Git e GitHub
