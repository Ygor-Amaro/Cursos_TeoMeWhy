# 🧙‍♂️ Aprenda SQL: Primeiras Magias na Linguagem dos Dados

Este repositório documenta meus estudos e resoluções de exercícios baseados no curso gratuito [Aprenda SQL](https://www.youtube.com/watch?v=VmkJG8awKqM&list=PLr88TGGyRbPQaEjdqbTUdYcKMZfYzsjiJ) ministrado pelo Téo Calvo (canal Téo Me Why). 

O foco do repositório é consolidar a base da linguagem de consulta estruturada, essencial para atuar como Analista, Cientista ou Engenheiro de Dados.

## 🎯 Objetivos de Aprendizado
* Escrever consultas (queries) eficientes para extração de dados em bancos relacionais.
* Realizar cruzamentos de tabelas (JOINs) e agregações (GROUP BY).
* Traduzir regras de negócio e perguntas operacionais em código SQL.
* Utilizar dados históricos para gerar insights e apoiar a tomada de decisões.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** SQL
* **Ambiente:** VS Code / Git Bash
* **Versionamento:** Git e GitHub
