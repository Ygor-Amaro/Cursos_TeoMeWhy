# 📊 Portfólio de Estudos em Dados: Téo Me Why

Este repositório contém meus estudos, anotações e projetos desenvolvidos com base nos cursos e lives do canal [Téo Me Why](https://www.youtube.com/@teomewhy). O objetivo é evoluir em engenharia, análise e ciência de dados por meio de projetos práticos e fundamentação teórica.

## 📚 Trilhas e Projetos

Abaixo estão os links oficiais das playlists e repositórios de apoio para cada frente de estudo:

### 1. SQL
Focado no aprendizado prático de consultas a bancos de dados relacionais, essencial para extração, manipulação e transformação de dados em regras de negócio.
* **Playlist Oficial:** [Aprenda SQL - Primeiras Magias na Linguagem dos Dados](https://www.youtube.com/@teomewhy/playlists)

### 2. Estatística
Conceitos fundamentais de probabilidade e estatística aplicados a dados, focando em sair do "achismo" para validar hipóteses reais do dia a dia.
* **Playlist Oficial:** [Estatística 2025](https://www.youtube.com/@teomewhy/playlists)
* **Repositório de Apoio:** [TeoMeWhy/estatistica-2025](https://github.com/TeoMeWhy/estatistica-2025)

### 3. Machine Learning
Construção de modelos preditivos, englobando todo o fluxo de treinamento, testes e avaliação de algoritmos de aprendizado de máquina.
* **Playlist Oficial:** [Machine Learning 2025](https://www.youtube.com/@teomewhy/playlists)
* **Repositório de Apoio:** [TeoMeWhy/ml-4-poneis](https://github.com/TeoMeWhy/ml-4-poneis)

### 4. Projeto: TSE Analytics
Projeto completo ponta a ponta (End-to-End) focado na coleta, processamento e disponibilização de dados utilizando as bases abertas do Tribunal Superior Eleitoral.
* **Playlist Oficial:** [TSE Analytics 2026](https://www.youtube.com/@teomewhy/playlists)
